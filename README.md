Day02
---------------------
grep [-n] 关键字 文件路径：从文件中通过关键字过滤出文件行。（-n显示过滤出的文件行数）<br>
wc [-c -m -l -w] 文件路径：统计文件的行数<br>
管道符（|）：将管道符左边命令的结果作为右边命令的输入<br>
echo "输出的内容"：在命令行内输出指定的内容<br>
反引号``：将反引号里面的内容作为命令执行<br>
重定向符（>）:将左侧命令的结果，覆盖到符号右侧的指定文件中<br>
        (>>):将左侧命令的结果，追加写入到符号右侧的指定文件中<br>
tail [-f -num] Linux路径：查看文件的尾部内容，跟踪文件的最新更改<br>
